# Тривога БПЛА STAN — Android (Rust)

Це стартовий навчальний макет. Він показує надану карту, дозволяє вибрати область
у списку та призначити їй один із чотирьох рівнів кольору або скинути статус.
Маркер на карті можна перетягувати вручну; він декоративний і не пов'язаний із
GPS, радарами, координатами чи реальним відстеженням.

## Файли
- `assets/map.jpg` — завантажена вами карта.
- `assets/photos/беспилотник.png` — сюди додайте власне PNG-зображення маркера.
- `assets/icon.png` — ескіз іконки (для повноцінної іконки APK її потрібно додатково
  прописати в Android packaging-конфігурації).

## Збірка APK
Потрібні Rust, Android SDK, Android NDK та `cargo-apk`.
1. Встановіть Android target: `rustup target add aarch64-linux-android`
2. Встановіть cargo-apk: `cargo install cargo-apk`
3. Налаштуйте змінні Android SDK/NDK згідно з інструкцією cargo-apk.
4. У корені проєкту виконайте: `cargo apk build --release --target aarch64-linux-android`

Готовий APK cargo-apk збере у каталозі `target/` (точний шлях залежить від версії
cargo-apk та конфігурації Android).

## Важливо
Наразі це початковий код: кольори зберігаються лише в пам'яті до закриття програми.
Растрова карта використовується як фон, тому цей прототип не перефарбовує контури
областей на самій карті. Для точного зафарбовування потрібен окремий векторний
шар із межами областей (GeoJSON/SVG), якого у вихідному зображенні немає.
